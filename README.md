# PACOSOFT

Phần mềm sổ sách kế toán theo Thông tư 99/2025/TT-BTC: nhập sổ từ Excel hoặc gõ tay, kết chuyển cuối kỳ, in sổ sách và báo cáo tài chính bằng tiếng Việt, Việt – Hoa, Việt – Anh.

Trang này chỉ chứa bộ cài. Phần mềm đã cài tự kiểm bản mới tại đây.

## Tải về

Vào [bản phát hành mới nhất](https://github.com/dacthinh05/pacosoft2026-ban-cai/releases/latest), mục **Assets**, tải file `PACOSOFT-Setup-<phiên bản>.exe`. Cần Windows 10 hoặc 11, 64-bit.

Windows hiện "Windows protected your PC" khi chạy bộ cài: bấm **More info**, rồi **Run anyway**. Bộ cài chưa có chữ ký số của nhà phát hành.
